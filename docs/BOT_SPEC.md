# 디스코드 작업 관리 봇 지침서

## 목적
한 사람이 두 계정으로 서버 공용 작업 목록을 관리한다. 계정별 소유권은 두지 않는다.
입력과 조작은 최소화한다. 서버별 데이터는 분리한다.

## 정보와 날짜
의뢰자명, 곡 제목, 착수일, 마감일을 저장한다. 내부 ID와 상태(active/completed/cancelled)는 시스템이 관리한다.
착수일은 생략하면 KST 기준 오늘로 설정한다. 직접 입력하면 과거·현재·미래 모두 가능하다. 날짜 형식은 YYYY-MM-DD이며 KST 달력 날짜로 계산한다.
주말과 공휴일을 포함한다. 의뢰자명·곡 제목은 앞뒤 공백을 제거한다.
의뢰자명+곡 제목+착수일이 모두 동일하면 아카이브를 포함해 중복 생성할 수 없다.

## 명령어
- `/작업 생성 의뢰자명 곡제목 마감 [착수일]`: 마감은 자동완성의 빠른마감(+3일), 일반마감(+14일) 또는 직접 입력한 0 이상의 정수 일수다. 착수일에 더하여 마감일을 계산한다.
- `/작업 확인`: 모든 미완료 작업을 조회한다. 미래 착수 작업도 포함한다.
- `/작업 연기 프로젝트 마감일`: 기존 마감보다 뒤인 날짜로 변경한다.
- `/작업 마감일변경 프로젝트 마감일`: 지정 날짜로 변경한다. 착수일 이전 날짜는 허용하지 않는다.
- `/작업 완료 프로젝트`: 완료 상태로 보관하며 기본 조회·알림에서 제외한다.
- `/작업 취소 프로젝트`: 취소 상태로 보관하며 기본 조회·알림에서 제외한다.

작업 선택 후보는 `의뢰자명 - 곡 제목 (착수 YYYY-MM-DD 요일, 마감 YYYY-MM-DD 요일)`이다. 필드 입력으로 의뢰자명·곡 제목·착수일·마감일을 검색한다. 긴 이름은 줄여도 후보의 날짜와 요일은 유지한다.
자동완성은 Discord 제한에 따라 최대 25개를 반환한다. 선택값은 내부 ID다.
작업 생성·변경·완료·취소 후 DB 처리가 완료된 뒤 미완료 목록을 다시 조회하여 처리 결과와 최신 목록을 같은 메시지에 응답한다. 완료·취소한 작업은 목록에서 제외한다. 별도 아카이브 조회·복원 기능은 제공하지 않는다.

## 표시와 정렬
번호 있는 목록으로 각 작업을 한 줄에 표시한다.
1. 의뢰인 - 곡 제목 (**D-2**, 착수 2026-10-22, 마감 2026-10-25)

D 값은 오늘(KST) - 마감일이다. 양수는 D+2, 0은 D±0, 음수는 D-2로 표시한다.
D 값 내림차순: D+2 → D±0 → D-3 → D-14. 같은 마감일이면 착수일, 내부 ID 순이다.
작업이 없으면 `현재 미완료 작업이 없습니다.`라고 표시한다.
메시지 길이 제한을 넘으면 여러 메시지로 나누며 번호는 이어진다. 사용자 입력으로 멘션을 발생시키지 않는다.

## 매일 알림
매일 서버별 설정 시각(KST, 기본 09:00)에 지정 서버 채널로 새 메시지를 전송한다. 내용은 `/작업 확인`과 같다.
`/설정 확인`을 실행하면 현재 설정을 본인에게만 표시한다.
`/설정 변경 채널:#채널 시각:18:30 알림:True`로 변경한다. 각 옵션은 생략 가능하며 생략한 값은 유지한다.
시각은 00:00~23:59의 HH:mm 형식이다. 채널을 처음 지정하면 알림이 켜지며, 알림 옵션으로 끌 수 있다.
설정은 서버별로 DB에 보관한다. 채널 미설정 시 알림은 꺼져 있다. 봇의 채널 보기·메시지 보내기 권한을 검사한다.
기존 환경 변수 채널은 최초 기본값으로만 가져오며 이후 DB 설정을 우선한다.
같은 날짜의 성공한 알림은 재시작 후 재전송하지 않는다. 실패 시 재시도하고, 당일 설정 시각 이후 재시작하면 미전송 알림을 보낸다.

## 운영
관리 권한은 Discord 명령어 권한 설정으로 제한할 수 있다. 서버 멤버 기본 권한은 서버 관리 권한으로 제한하며, 운영자가 두 계정에 명령어 사용 권한을 부여한다.
테스트와 운영은 각각 별도 토큰·DB·알림 채널을 사용한다.

설정 변경은 다음 알림 확인 주기(최대 약 30초)부터 적용한다. 오늘 이미 성공한 알림은 채널·시각을 변경해도 다시 보내지 않는다. 오늘 아직 보내지 않았고 설정 시각이 지났으면 다음 확인 시 보낸다.

작업 명령어 별칭: `/작업 목록` = `/작업 확인`, `/작업 추가` = `/작업 생성`, `/작업 파기`·`/작업 중단` = `/작업 취소`. 입력 옵션, 자동완성, 처리 결과는 원래 명령어와 동일합니다.
